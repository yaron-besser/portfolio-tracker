# Theme write-ups from one research letter

One file per theme in a single quarterly letter, each summarising that
publisher's own argument and the figures they quoted for it.

> **Summaries of someone else's work.** Copyright in the underlying letter
> belongs to its publisher; no redistribution rights are claimed. The letter
> itself is not in this repository.

Sections comparing these themes against a particular portfolio have been
removed — those were the reader's, not the publisher's, and they are the part
this public copy deliberately does not carry.
