# Cluster: Technology (demo note)

> **Demo note.** Synthetic text, written to exercise this project's
> note-shape rules against a generated book. Not investment advice.

## Why this cluster exists

A group, not a theme. It holds three themes that are each a different
altitude of one bet — the hardware, the software, and the applications — and
it exists so that bet can be seen whole.

Without it, three rows each look like a moderate position and the total
never appears anywhere. That was the actual failure this layer was added to
fix.

___

## What would end it

Nothing ends a group. It ends when the themes inside it do.

What would end all three at once is the capital-spending cycle turning, which
is the shared dependency and the reason they are grouped rather than listed.

___

## Reading its weight

A group carries its children's money, so summing every cluster row
over-counts. Run `clusters.weights()` and read the rows where `is_group` is
False. The number is never written down here.
