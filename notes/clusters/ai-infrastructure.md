# Cluster: AI Infrastructure (demo note)

> **Demo note.** Synthetic text, written to exercise this project's
> note-shape rules against a generated book. Not investment advice.

## Why this cluster exists

The physical layer underneath everything that gets called AI: the
accelerators, the tooling that makes them, and the foundry capacity that
turns a design into a part.

It is a deliberate overweight. The index funds in Core US already own these
names at index weight. This theme is extra weight on top of that, held
directly, so the exposure is not diluted by everything else an index holds.

___

## What would end it

The capital-spending cycle turning, so the demand that funds the whole theme
stops being renewed.

Or the slower version of the same ending: the spending continues and stops
earning a return on itself.

Neither is a trigger and neither is a rule. This section records what would
make the reason for the theme untrue, so a later reader can tell the
difference between a thesis failing and a price falling.

___

## What it is watching

How the build-out is being financed, and whether the companies doing it can
show a return on it. If the spending is seen to be inefficient, the
unwinding is likely to be fast rather than gradual.
