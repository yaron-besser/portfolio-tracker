# DRAM — A memory-sector fund (demo note)

> **Demo note.** Synthetic text, written to exercise this project's
> note-shape rules against a generated book. It is not investment advice
> and not anyone's real view of anything.

Memory is one of the constraints in the hardware build-out. This is the
narrow way to own it rather than a broad semiconductor fund that dilutes
it. On the watchlist rather than in the book.

## Bear case

Memory is the most cyclical part of a cyclical industry. 'This cycle is
different' is the expensive sentence here.

A fund this narrow is three or four manufacturers. If one disappoints the
whole thing takes it.

## Catalysts

- [ ] Pricing power holds through the build-out

## Why this note exists for something not held

A name being considered gets a note before it gets a position, so the
reasoning is on file before the money is. The writing queue orders by
money, so a watchlist note is never urgent — which is why it has to be
written when the thinking happens rather than when the trade does.
